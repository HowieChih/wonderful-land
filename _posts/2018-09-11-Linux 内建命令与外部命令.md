1、外部命令
外部命令，有时候也被称为文件系统命令，是存在于bash shell之外的程序。它们并不是shell程序的一部分。外部命令通常位于/bin、/usr/bin、/sbin或／usr/sbin中。当执行这些外部命令的时候，会创建一个子进程。这种操作被称为衍生。当进程执行衍生操作时，它需要花费时间和精力来设置新子进程的环境。所以说，外部命令多少还是需要代价的。

2、内建命令
内建命令和外部命令的区别在于前者不许使用子进程来执行。它们已经和shell编译成一体，作为shell工具的组成部分存在。不需要借用外部程序来运行。因为既不需要通过衍生出子程序来执行，也不需要打开程序文件，内建命令的执行速度要更快，效率也更高。

type 命令
The type command in Linux is used to find out how a command that you enter will be interpreted – as a built-in command, external command, or an alias.

Linux 默认执行哪种命令
```
type cd
 // cd is a shell builtin
type ls
// ls is aliased to `ls --color=auto`
type ps
ps is /usr/bin/ps
```

type -t command
file 外部命令
alias 命令别名
 builtin 内置命令

type -a cd
// output
cd is a shell builtin
cd is /usr/bin/cd

**这里就可以看出来 cd 既是有内置命令，又有外部命令。**

1、which 命令查不到程序文件所在位置的命令都是内置。

2、内置命令没有 --help 选项，但有些系统的外部命令也没有 --help选项，比如macOS ls（https://unix.stackexchange.com/a/207139）。内部命令和外部命令同名，可以使用文件路径来使用，比如某些系统（比如centos）pwd做为外部命令时，会有help选项，/bin/pwd --help

3、内建命令没有单独的man手册，man 内置命令会展示所有内建命令相关的信息，可以使用 help 来操作。

不同类型的命令执行顺序
https://www.jianshu.com/p/28da1ed0d830

hash：系统初始hash表为空，当外部命令执行时，默认会从PATH路径下寻找该命令，找到后会将这条命令的路径记录到hash表中，当再次使用该命令时，shell解释器首先会查看hash表，存在将执行之，如果不存在，将会去PATH路径下寻找。利用hash缓存表可大大提高命令的调用速率。

1、内部命令>hash>外部命令
2、当一个内部命令有同名的别名命令，系统会执行它的别名命令。
3、当一个外部命令有同名的别名命令，系统会执行它的别名命令。
