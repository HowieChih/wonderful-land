**uptime**
系统运行时间

```
$ uptime
1:12  up 29 days, 23 hrs, 2 users, load averages: 3.37 2.56 2.26
当前时间，运行时间，用户数量，负载
```

硬件时间与软件时间
一台Linux服务器有两个时间源，一个是硬件时间，即服务器硬件CMOS维护的时间，靠主板电池来维护。还有一个是软件时间，即操作系统维护的时间，靠cpu tick来维持。两个时间互不干扰，如果发现不一致，需要同步。前者使用clock命令，后者使用date命令。

**date**

```
// display the current system date and time
date
// operate on a specific date
date -d "2018-10-18 17:56:54"
// provide date with the formatting string by prefixing it with a plus sign, using date --help display
// formatting options
date +"%Y-%m-%d %H:%M:%S"
// seconds from epoch(seconds since 1970-01-01 00:00:00)
date +%s
// convert epoch to a date
date -d @126507600
```

```
// set time
date -s 20160823
date -s 01:01:01
date -s "2015-08-21 01:01:01"
date -s "20150821 01:01:01"
```

```
date -d now
date -d today
date -d yesterday
// other valid date time strings include: tomorrow, sunday, last-sunday, last-week, next-week, last-month, // next-month, last-year and next-year
```

**clock**
clock命令与hwclock是同一个命令，主要用来查询和设置硬件时钟（query and set the hardware clock/RTC）,RTC=real time clock。

```
// 显示硬件时钟时间
sudo clock
sudo clock -r
// 将硬件时钟同步到系统时钟 set the system time from the hardware clock
sudo clock -s
// 将系统时钟同步到硬件时钟 set the hardware clock to the current system time
sudo clock -w
// 设置硬件时间 --date选项其实就是date程序的参数
sudo clock --set --date="9/22/96 16:45:05"
```

**NTP**
Linux操作系统维护的软件时间随着服务器的长时间运行会出现漂移，最终会越来越不准确。不准确的系统时间会对依赖时间的服务带来影响，例如数据库，认证等，因此需要维持一个相对准确的服务器时间。

NTP协议，Network Time Protocol

implementations of NTP:
chrony-version
ntp-version（程序名字叫ntp，起作用的服务名字叫ntpd）
openntpd-version
等等，还有很多其他实现，详见Wikipedia。
上面3个实现的区别见chrony官网：https://chrony.tuxfamily.org/comparison.html

In RHEL 7 ntpd is replaced by chronyd as the default network time protocol daemon.虽然这样说，但centos里面如果想用chrony，还是要自己安装。用户可以自己选择是装ntp还是chrony。

```
yum search ntp
-------------------
ntp.i686 : The NTP daemon and utilities(ntpd service which continuously adjusts system time and utilities used to query and configure the ntpd daemon.)   // ntpd
ntp-doc.noarch : NTP documentation
ntpdate.i686 : Utility to set the date and time via NTP
chrony.i686 : An NTP client/server
```

ntpd与ntpdate区别：ntpdate一次性调整到需要的时间，ntpd慢慢偏移到。

*ntp同步好系统时间之后，再设置硬件时间与系统时间一致*。

```
yum install ntp ntpdate ntp-doc

// synchronize the system clock with 0.pool.ntp.org server, use this command only once or as // required
ntpdate pool.ntp.org 

// ntpdate deprecated 后，可以用如下命令代替
ntpd -q

// start the ntp server, the following will continuously ajusts system time from upstream 
// NTP server，如果启动有问题，可以试试sudo
/etc/init.d/ntpd start

// ntp 服务运行后，通过如下命令查看与上游时间服务器的同步情况
ntpq -p
```

**时区**
对于大部分Linux系统，各个时区设置文件放在/usr/share/zoneinfo/中，将/etc/localtime通过文件链接指向欲设置的时区配置文件即可。例如：

```
// 将系统时区改为上海时间 (亦即CST时区)
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
```
