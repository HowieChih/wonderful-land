# 一、忽略已经到远程的内容
.idea 目录已经push到远程，现在想要untrack，在.gitignore中添加了 .idea/ 后，观察到

1、在该目录下新增的文件，git status中不会出现变化，意味着这些新文件track规则已经生效了。
2、原有的tracked的文件，git status中会出现其变化。

执行 ``git rm --cached file.xml`` 或者 ``git rm --cached -r .idea/`` 告诉git不再track指定文件或者指定目录。
执行 git status 后可以看到删除追踪状态的文件以如下方式列出：

```
deleted:    .idea/a.xml
deleted:    .idea/b.xml
```

本地物理文件继续存在。刚新增还未track的文件，不会受上述命令影响。

继续 add commit push 之后track规则就会影响到远程仓库，远程仓库相应的文件也会删掉。

这样即可，其他团队成员更新到自己本地时就不会受影响了。

另外一种解决方法：rm 掉需要忽略的本地文件，重新编辑gitignore文件，走ignore流程

# 二、foo/ 和 foo/** 区别

**`foo/`** 只忽略文件夹的直接内容，不递归。

- foo/file1.txt  -> 被忽略 
- foo/subdir/  -> 不会忽略

**`foo/**`** 递归忽略文件夹的所有内容，适合用来彻底忽略整个目录树。
